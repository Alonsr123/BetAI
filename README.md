# BetAI V1

Prototipo PWA privado de análisis de partidos.

## Ejecutarlo
1. Descomprime el proyecto.
2. Sirve la carpeta con un servidor local (por ejemplo `python -m http.server`).
3. Abre la dirección local en el navegador.
4. En móvil, usa "Añadir a pantalla de inicio" para instalarla como PWA.

## Incluye
- Inicio
- Lista de partidos
- Filtros por liga
- Ficha de partido
- Probabilidades de demostración
- xG de demostración
- Mis apuestas
- Navegación móvil
- Manifest + Service Worker

Los datos actuales son ficticios y no deben utilizarse para tomar decisiones reales.
